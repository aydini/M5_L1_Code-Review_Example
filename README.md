A simple python project to demo good code review practices (reference: Module 5 Lecture 1 notes, fall'26 of CSC 325)

a demo using VS Code and Github to show
* how to read diff output in github,
* how to create a Pull Request from a branch (assign reviewers including assigning copilot to be a reviewer, add the PR to the project kanban board),
* how to write good code reviews using strategies mentioned in M5-L1 slide deck mentioning the severity: blocking, suggestion, nit, question
